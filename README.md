# Consumo de API com Python

Projeto simples para praticar consumo de API com `requests`, leitura de JSON, uso de funções e filtros em listas/dicionários.

## O que o projeto faz
- Faz requisição para a API JSONPlaceholder
- Verifica se a resposta foi bem-sucedida
- Converte os dados JSON para Python
- Percorre os usuários retornados
- Filtra usuários com cidade contendo 10 ou mais caracteres

## Tecnologias
- Python
- Requests

## Aprendizados
- Uso de `requests.get()`
- `status_code`
- `.json()`
- `return`
- listas e dicionários aninhados
- condicionais com booleanos
